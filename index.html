HARDENv2

HARDENv2 is a bytecode-level smart contract vulnerability detection project built around heterogeneous graph structure, enriched opcode features, and multi-label prediction across ten SWC categories.

This site highlights the retained public artifact surface: code, curated graph artifacts, benchmark splits, retained feature tables, and publication-facing evaluation bundles.

Research Focus

Bytecode-only multi-label vulnerability detection with CFG and DFG-aware heterogeneous graph modeling.

Benchmark

CGT-DAppSCAN with 2,186 contracts and ten evaluated SWC categories.

Pipeline Map

The retained pipeline spans benchmark curation, graph recovery, feature extraction, and multi-label training.

1

Curate

Merge and harmonize CGT and DAppSCAN labels and contract records.

2

Build Graphs

Recover CFG and DFG structure from runtime bytecode.

3

Extract Features

Produce TF-IDF, pattern, graph-level, and related opcode features.

4

Configure

Retain the Phase 4, Phase 5, and Phase 7 configuration chain.

5

Train And Evaluate

Run OpcodeGT and baselines, then aggregate publication-facing metrics.

pip install -r requirements.txt
python -m src.training.run_experiments --config configs/phase7_balanced.yaml
python scripts/level4_analysis.py --manifest reports/phase7_balanced/phase7_run_manifest.json

These commands cover the retained training and aggregation path.
