# Synthetic EG Contracts

This directory mirrors the ten Solidity listings in the paper's appendix
section "Synthetic E-Government Contract Validation."

The files are verbatim extracts of those appendix listings. They are
illustrative sanity-check contracts, not CGT-DAppSCAN benchmark members.
